# ⚙️ automations

No-code and low-code automations I've built to solve real problems.  
Built with n8n, Zapier, Make, and whatever gets the job done.

---

## Philosophy

> Automate the boring. Focus on the thinking.

As a PM, I spend a lot of time on repetitive tasks — status updates, report pulls, meeting summaries.  
This repo is my running list of workflows that give me that time back.

---

## Workflows

| Workflow | Tool | Description | Status |
|----------|------|-------------|--------|
| Meeting notes → Notion | n8n | Auto-summarise meeting transcripts and push to Notion | 📋 Planned |
| Weekly report generator | Make | Pull data from multiple sources into a report | 📋 Planned |
| Slack digest bot | Zapier | Daily digest of key Slack channels | 📋 Planned |

---

## How to use

Each folder contains:
- A `README.md` explaining the workflow
- The exported workflow file (`.json` for n8n, etc.)
- Setup instructions
